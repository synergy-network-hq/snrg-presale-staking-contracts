# Mainnet deployment record

`contracts.json` is the authoritative address, creation transaction, block,
runtime-bytecode hash, ABI-path, and explorer-verification record for release commit
`bfbdf432fbacbdd6570bc546250a3da0990ea5b9`.

The individual ABI files are under `abis/`. `safe-base-8453.json` and
`safe-ethereum-1.json` are Safe Transaction Builder batches. They are pending until
the governance Safe executes them; their presence is not evidence that staking is active.

No private key, RPC credential, explorer key, attestor keystore, relayer keystore, or
mTLS private material belongs in this directory.
